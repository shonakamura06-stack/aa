# E2E Skill

Write end-to-end tests for a user flow.

## Input
Flow description, e.g. "signup: register, verify email, first login, onboarding".

## Steps
1. Detect E2E framework (Playwright/Cypress)
2. Map flow to steps and assertions
3. Handle selectors, waits, auth state
4. Include cleanup/teardown
5. Add to test suite

## Usage
`/e2e <flow description>`
