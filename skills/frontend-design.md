# Frontend Design Skill

Design and implement production-ready frontend UI.

## Principles
- Mobile-first responsive layouts
- Clear visual hierarchy and spacing scale
- Accessible (ARIA, contrast, keyboard nav)
- Consistent design tokens (colors, spacing, type)
- Reusable components

## Steps
1. Clarify target (page/component, brand, audience)
2. Propose layout wireframe + design tokens
3. Implement with semantic HTML + CSS/Tailwind
4. Add responsive breakpoints
5. Verify accessibility basics
