# Test Coverage Skill

Analyze the codebase to find untested or under-tested code paths.

## Steps
1. Detect testing framework (Jest, Vitest, pytest, etc.) and existing patterns
2. Map source files to test files
3. Identify untested functions/branches/edge cases
4. Generate tests following project conventions
5. Suggest missing edge cases (null, empty, boundary, error paths)

## Output
- Coverage gaps list
- Generated test files/snippets
- Recommendations to reach target coverage

## Usage
`/test-coverage` or "find untested code and generate tests"
