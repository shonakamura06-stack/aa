# Impeccable Skill

Polish and improve an existing web design.

## Focus areas
- Spacing and rhythm (consistent scale)
- Typography (scale, line-height, measure)
- Color (contrast, palette coherence)
- Visual hierarchy
- Alignment and grid
- Micro-interactions and states (hover, focus, empty, loading, error)

## Steps
1. Audit current UI against checklist
2. List issues with screenshots/refs
3. Apply fixes in priority order
4. Verify across breakpoints

## Usage
`/impeccable` or "polish this UI"
