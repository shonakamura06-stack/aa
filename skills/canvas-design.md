# Canvas Design Skill

Create aesthetic design philosophies and render them on canvas.

## Steps
1. Define aesthetic movement / design philosophy (mood, principles)
2. Create canvas composition (shapes, type, color)
3. Export assets (.png, .pdf) and spec (.md)

## Output
- Design philosophy document
- Canvas renders
- Usage guidelines

## Usage
`/canvas-design <theme>`
