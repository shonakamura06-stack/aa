# FFmpeg Video Skill

Media processing with ffmpeg.

## Capabilities
- Cut/trim, concat
- Format conversion (mp4, webm, gif)
- Compression and resize
- Audio extraction and mixing
- Subtitle burn-in
- Batch processing

## Usage
`/ffmpeg-video <operation>`
