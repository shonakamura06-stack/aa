# Document Skill

Generate documentation for a file, module, or function.

## Steps
1. Read code and infer intent/purpose
2. Detect doc style (JSDoc, docstrings, README sections)
3. Write concise, accurate docs
4. Include params, returns, throws, examples where useful
5. Avoid restating obvious code

## Usage
`/document <file or symbol>`
