# Skills para Claude Code / Arena AI Agent Mode

Colección de skills en formato Markdown (`.md`) organizadas para subir a GitHub y usar en **Arena AI Agent Mode** (o Claude Code).

## Estructura
Cada archivo `.md` es una skill independiente con frontmatter YAML (`name`, `description`) y el prompt/instrucciones.

## Categorías
- **Código:** code-review, security-audit, test-coverage, create-pr, commit-fast, refactor, architect, document, changelog, test, e2e, deploy, compact, loop, batch
- **Diseño web:** frontend-design, impeccable, ui-ux-pro-max, web-design, web-artifacts-builder
- **Diseño/Canvas/Brand:** canvas-design, brand-design
- **Imágenes:** higgsfield-image
- **Videos:** remotion-video, claude-youtube, higgsfield-video, ffmpeg-video
- **Creatividad:** skill-creator, adobe-creativity
- **Humanizar texto:** humanizer, humanize-writing

## Uso
1. Copia los `.md` a `.claude/commands/` (Claude Code) o a la carpeta de skills de tu agente.
2. Invoca con `/nombre-del-archivo` (sin extensión) o según el agente.
3. Para GitHub: sube esta carpeta `skills/` al repo; Arena AI Agent Mode puede leer los `.md`.
