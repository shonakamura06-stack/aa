# Web Artifacts Builder Skill

Build rich web artifacts (apps, dashboards, tools) using modern stack.

## Stack
- React + TypeScript
- Tailwind CSS
- shadcn/ui components
- Multi-file structure

## Steps
1. Clarify artifact goal and features
2. Scaffold project structure
3. Implement components
4. Add styling and responsiveness
5. Test and preview

## Usage
`/web-artifacts-builder <description>`
