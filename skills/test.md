# Test Skill

Generate tests for specified code.

## Steps
1. Read implementation
2. Detect framework (Jest, Vitest, pytest, etc.)
3. Identify happy path, edge cases, error paths
4. Write tests matching project style and imports
5. Include mocks/stubs as needed

## Usage
`/test <file or function>`
