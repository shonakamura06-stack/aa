# Architect Skill

Design system architecture for a feature request before coding.

## Steps
1. Clarify requirements and constraints
2. Map data flow (inputs, transformations, outputs, storage)
3. Identify affected components/services
4. Consider tradeoffs (performance, complexity, scalability, cost)
5. Propose architecture with diagrams (mermaid) and file plan
6. List risks and open questions

## Output
- Architecture overview
- Component diagram
- Data flow
- File/module plan
- Tradeoffs and risks

## Usage
`/architect <feature description>`
