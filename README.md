## Trazador · Math Wars

Plano cartesiano interactivo para planear tiros en Math Wars (Roblox): dibujas la curva con
puntos (o escribes `f(x)`), se detectan los choques con los bloques y te da la ecuación lista
para pegar. Diseño claro en beige, pensado también para el móvil.
Ver [`trazador/`](trazador/README.md) · En línea: <https://trazador-math-wars.vercel.app>
